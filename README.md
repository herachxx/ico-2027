## What Is Inside

These writeups are made to be readable even if someone is new to CTFs.

Each task writeup explains:

- what the challenge asked me to do;
- what the important abbreviations and tools mean;
- how I investigated the files or remote service;
- why the vulnerability or trick worked;
- the commands and scripts I used;
- the final flag or final result.

## Notes

`ICO` stands for `International Cybersecurity Olympiad`.

`CTF` stands for `Capture The Flag`. In cybersecurity competitions, a flag is a secret string hidden inside a challenge. The goal is to find it by analyzing files, programs, websites, network services, or other provided materials.

Everything in this repository is for educational CTF learning only. The techniques are explained in the context of competition tasks and should be used only in legal environments where testing is allowed.
