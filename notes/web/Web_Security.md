# Web Security

## Authentication

Who are you?

Examples: - passwords - tokens - sessions

## Authorization

What can you access?

## SQL Injection

User input changes SQL queries.

## XSS

Injected JavaScript executes in another user's browser.

## IDOR

Changing object identifiers to access unauthorized data.

Example:

/user/100

becomes:

/user/101

## Burp Suite

Main tools:

Proxy: intercept requests

Repeater: modify requests manually

Intruder: automated testing
